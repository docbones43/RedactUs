# Browser Extension — Paid Tier

The RedactUs browser extension is **not** developed in this public repository.

It intercepts text inside Perplexity, ChatGPT, Claude, and Gemini before submission, so
you don't have to copy-paste through the standalone tool.

Development lives in the private `docbones43/RedactUs-pro` repository. When the
extension reaches a public preview, install instructions will appear here and in the
root [`README.md`](../README.md).

If you want the free, MIT-licensed engine that powers the extension under the hood, see
[`/standalone/`](../standalone/) — it ships today and works in any browser.
